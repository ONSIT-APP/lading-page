# SIT — Landing page comercial

Apresentação do SIT em HTML, CSS e JavaScript puro. Layout responsivo, fotografia, fonte Manrope local e soluções para empresas, governos e pessoas.

## Visualizar

Abra `index.html` no navegador. Mantenha a pasta `assets` ao lado dos três arquivos principais. Não é necessário instalar dependências ou compilar.

## Estrutura

- `index.html`: apresentação, soluções e conteúdo institucional.
- `styles.css`: identidade visual, tipografia e adaptação às telas.
- `script.js`: seleção dos públicos, navegação por teclado e links internos.
- `assets/`: fotografias, fontes e licença da Manrope.
- `favicon.svg`: símbolo do SIT.

A navegação é exclusivamente comercial e permanece na página. Não existem links de login, cadastro ou acesso ao sistema, formulários sem destino ou indicadores fictícios.

Os textos são editados no HTML. As cores e a margem lateral ficam nas variáveis no início do CSS. As abas funcionam com as setas esquerda/direita e Home/End. É possível compartilhar `?publico=empresa`, `?publico=governo` ou `?publico=candidato`.
